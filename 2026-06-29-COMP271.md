## From TrainLine to Linked List

We opened by revisiting the `TrainLine` assignment — the `add`, `contains`, `indexOf`, `indexOfAll`, `returnCount`, and `remove` methods — and used it as a bridge to a more general data structure. One observation worth carrying forward: `contains` and `indexOf` share redundant logic; `contains` could simply call `indexOf` and check whether the result is meaningful. We'll see a cleaner version of that relationship in the structure we're building now.

## Method Overloading and Python's Type Hints

Before moving on, we looked at one enhancement to the `add` method: what if the caller passes a plain string instead of a `Station` object? Using `isinstance(new_item, str)`, we can detect that case, construct a `Station` from the string, and proceed. In Java this would be method overloading — two `add` signatures, one accepting a `String` and one a `Station`. Python handles it with an `if` check instead. Along the way we saw that type annotations (`: str`, `: Station`, `: T`) are hints, not contracts; Python runs the code regardless of whether the argument matches the declared type.

## The Node Class with a Generic Payload

We introduced `Node` as the fundamental building block of a doubly linked list. Using `TypeVar` and `Generic` from Python's `typing` module (plus `from __future__ import annotations`), we defined a type parameter `T` so a node's payload can be any object — a string, an integer, a `Station`, a keyboard event — without changing the class. Each node carries three fields: `payload` (of type `T`), `next` (another `Node` or `None`), and `previous` (another `Node` or `None`), both defaulting to `None`.

## Doubly Linked Lists and Their Flexibility

A doubly linked list lets us traverse in either direction: forward by following `next` pointers, backward by following `previous` pointers. The head node's `previous` is `None`; the tail's `next` is `None`. We can still model a unidirectional structure (like the southbound Red Line from Howard to 95th) by simply leaving the `previous` pointers at `None` — a doubly linked node used in one direction.

## Stacks, Queues, and Next Steps

We previewed two abstractions built on top of linked lists: a **queue** (first in, first out — like a grocery checkout line) and a **stack** (last in, first out — like undo/redo). We'll explore both in depth this week, along with how to detect discontinuities in a bidirectional list.
